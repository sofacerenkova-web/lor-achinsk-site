# Центр ЛОР Ирины Сеновой — тестовый лендинг

Тестовая версия одностраничного сайта ЛОР-центра (Ачинск). Закрыта от индексации (`noindex`, `robots.txt: Disallow: /`).

**Перед публикацией на боевом домене:**
- заменить `[ДОМЕН]` на реальный домен (canonical, Open Graph, JSON-LD);
- вернуть `<meta name="robots" content="index, follow">` и боевой `robots.txt` со ссылкой на sitemap;
- подставить данные лицензии, ОГРН, образование медсестры, ссылку на MAX;
- подключить отправку заявок с формы (сейчас форма заявки никуда не отправляет);
- приложить PDF-документы для раздела «Пациентам».

Иллюстрации в блоках услуг и методик сгенерированы ИИ — заменить на реальные фото клиники и аппаратов, когда будут.
